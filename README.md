# Jeevan Prasanth: Portfolio

Static site: no build step needed.

## Run
Open `index.html` in a browser (internet needed for the 3D background library).

## Edit
All content is in the script at the bottom of `index.html`:
- `RESUME_URL`: path to your resume PDF (see `assets/README.txt`)
- `SKILLS`, `PROJECTS`, `CERTS`: update text, add `links:[["View Project","https://..."]]` to a project when a real link exists

## Deploy
Drag this folder onto Vercel or Netlify, or push it to a GitHub repo and enable GitHub Pages.
